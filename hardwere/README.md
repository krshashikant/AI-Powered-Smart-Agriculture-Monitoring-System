Hardware Components

This folder contains the hardware details of the AI-Powered Smart Agriculture Monitoring System.

Components Used

- ESP32 Development Board
- Soil Moisture Sensor
- DHT11 Temperature & Humidity Sensor
- Relay Module
- Water Pump
- Jumper Wires
- Breadboard
- Power Supply

Description

These hardware components are used to collect environmental data and automate irrigation based on sensor readings.
