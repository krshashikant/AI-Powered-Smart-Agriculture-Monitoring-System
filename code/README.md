AI-Powered Smart Agriculture Monitoring System - Code

This folder contains the source code for the AI-Powered Smart Agriculture Monitoring System.

## Files

- app.py - Main Flask application
- sensor.py - Simulates sensor data (temperature, humidity, soil moisture)
- model.py - Machine Learning model for prediction
- train_model.py - Trains the ML model using dataset
- dashboard.py - Dashboard interface

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- Joblib
