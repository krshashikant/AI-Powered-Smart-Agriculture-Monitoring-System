# AI-Powered-Smart-Agriculture-Monitoring-System
An AI-powered IoT based Smart Agriculture Monitoring System using ESP32, Machine Learning and Flask Dashboard.
🌱 Project Overview

This project is an AI-powered Smart Agriculture Monitoring System that uses ESP32, IoT sensors, and Machine Learning to monitor crop conditions in real time. It helps farmers optimize irrigation, improve crop health, and reduce water usage.

 🚀 Features

- Real-time Soil Moisture Monitoring
- Temperature & Humidity Monitoring
- Automatic Irrigation Control
- AI-based Irrigation Prediction
- Live Dashboard using Flask
- Data Logging and Analysis

🛠️ Hardware Used

- ESP32
- Soil Moisture Sensor
- DHT11 Sensor
- Relay Module
- Water Pump
- Jumper Wires

 💻 Software Used

- Python
- Arduino IDE
- Flask
- VS Code
- GitHub
